# Updated Features - Multi-Contact Support

## What's New

The Stoic Calendar now supports **multiple email addresses and phone numbers** per user! This means you can:

- Add multiple email addresses (personal, work, etc.)
- Add multiple phone numbers
- Choose which contacts receive notifications
- Set primary contacts for each type
- Label your contacts for easy identification
- Enable/disable notifications for each contact individually

## How to Use

### Adding Contacts

1. Go to **Settings** page
2. Click **"+ Add Contact"** button
3. Select type (Email or Phone)
4. Enter the contact information
5. Optionally add a label (e.g., "Work", "Personal")
6. Click **Add Contact**

### Managing Contacts

Each contact can be:
- **Toggled for notifications**: Check/uncheck the "Notifications" checkbox
- **Set as primary**: Click "Set as Primary" to make it the default contact
- **Deleted**: Click "Delete" to remove it

### How Notifications Work

When you have multiple contacts:

- **Email Notifications**: If enabled in preferences, reminders will be sent to ALL email addresses that have "Notifications" enabled
- **SMS Notifications**: If enabled in preferences, reminders will be sent to ALL phone numbers that have "Notifications" enabled
- **Daily Quotes**: Sent to ALL enabled contacts based on your quote delivery preference (email or SMS)

### Primary Contacts

- Each contact type (email/phone) can have one primary contact
- The first contact you add is automatically set as primary
- You can change which contact is primary at any time
- Primary contacts are marked with a blue badge

### Example Use Cases

1. **Multiple email addresses**:
   - Personal email for non-urgent reminders
   - Work email for work-related events
   - Both receive notifications for important events

2. **Family sharing**:
   - Add your spouse's phone number
   - They'll receive SMS notifications for shared events
   - Each contact can be toggled independently

3. **Backup contacts**:
   - Primary and backup email addresses
   - Ensure you never miss important reminders

## Mobile Responsive

The entire app, including the new contacts manager, is fully mobile responsive:
- Optimized layouts for phones, tablets, and desktops
- Touch-friendly buttons and controls
- Easy to manage contacts on any device

## Migration

When you first start the updated app, any existing email/phone from your profile will automatically be added as a primary contact. No action needed!

## Tips

- Add multiple contacts before important events to ensure you don't miss reminders
- Use labels to organize your contacts
- Disable notifications for contacts you don't want to disturb at certain times
- The app will continue working even if some contacts fail (others will still receive notifications)
